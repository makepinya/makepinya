# PINYA

PINYA is an open system of modules that sense, process and act on the physical world.  
Each module has its own behavior; connect them to build something bigger.

- No central device: every module is self-contained. What the system does depends on how the modules are connected and how each one is configured.
- First modules: **MEASURE** and **LIGHT**.
- Documentation and firmware are on the way.

Follow the process on Instagram: [@makepinya](https://instagram.com/makepinya)
